# Astoria Grande — коммерческое предложение

Интерактивная HTML-презентация Content Factory для тендера Astoria Grande.

**Онлайн:** [GitHub Pages](https://paramanova-commits.github.io/astoria-grande-content-factory/)

## Содержание

- Концепция Content Factory, команда, бюджет, доп. работы
- Стартовые герои, контент-план, кейсы, ROI-модель
- Навигация по пунктам в шапке

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python3 -m http.server 8080
```

## Сборка из исходников

Исходники генерации — в родительской папке проекта (`build_presentation.py`, docx).

```bash
python3 build_presentation.py
```
